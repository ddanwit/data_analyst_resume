# Data Analyst Resume
### [Excel Проекты](https://github.com/ddanwit/Excel-Projects.git)
Калькулятор зарплат в Data Science: анализ реальных вакансий за 2023 год в Excel. Загрузка и трансформация данных в Power Query, построение модели в Power Pivot, расчёт медианной зарплаты на DAX, сводные таблицы и диаграммы, интерактивный дашборд с проверкой данных и защитой листов. Результат — инструмент, показывающий влияние навыков на уровень дохода.
### [Аналитика поведения потребителей](https://github.com/ddanwit/customer_shopping_behaviour_ananlysis.git)
Customer Shopping Behaviour Analysis: сквозной анализ покупок 3 900 клиентов. Очистка данных на Python (pandas, numpy), 10 бизнес-запросов в MySQL, дашборд в Power BI, отчёт и презентация в Gamma. Выявила, что экспресс-доставка связана с чеком на 3,4% выше; 5 товаров имеют долю дисконтных продаж выше 47%; сегментировала клиентов на Loyal, New и Returning с рекомендациями по удержанию.
